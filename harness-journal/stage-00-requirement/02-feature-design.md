### 原型草图

输出了 3 个 ASCII 原型：
1. **需求输入视图** — 左栏项目列表 + 中栏需求描述/技术栈/功能勾选 + 右栏快捷操作
2. **流程监控视图** — 顶部进度条 + 左栏 Agent 状态 + 右栏实时日志 + 底部反馈循环记录/熵管理
3. **产物管理视图** — 应用预览 + 产物清单 + 技术栈 + Harness 执行摘要

### 关键权衡

**能做的部分**：
- Harness 8 阶段流程可以编排成平台的后端引擎
- 约束管理可做成可视化配置面板
- 反馈循环、熵管理可做成后台自动化任务

**最难的部分**：
- Agent 运行时需要可靠的编排引擎调度多 Agent
- 模板覆盖面要足够广
- 质量信任取决于约束层严密度

**建议起步路径**：先选一个垂直方向（Spring Boot 管理后台），把 Harness 流程跑通，再横向扩展模板。
